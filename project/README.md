# Student Placement Portal — Azure Mini-Project

## Project objective
Propose a secure, manageable and cost-aware Azure architecture for a college placement portal.

## Users
- Students: view placement opportunities and submit documents.
- Placement officers: manage placement and company information.
- Developers: maintain and deploy the application.
- Cloud administrators: manage infrastructure and access.

## Functional needs
- Web application and backend API.
- Relational data for students, companies and placements.
- Document storage for resumes and certificates.
- Identity and permissions.
- Monitoring, troubleshooting and cost visibility.

## Scope
This is an infrastructure design exercise. It does not include application source code, a live deployment, real credentials or verified cost quotations.
