# Azure Infrastructure Fundamentals — Phase 2 (Weeks 1–8)

A GitHub-ready learning portfolio covering Azure fundamentals, infrastructure, networking, security, identity, monitoring, cost control and a mini-project architecture.

## Learning roadmap

| Week | Topic | Outcome |
|---|---|---|
| 1 | Azure cloud basics | Explain Azure resource organisation |
| 2 | Virtual machines | Explain how a cloud server works |
| 3 | Azure Storage | Understand secure file storage |
| 4 | Azure networking | Design a basic Azure network |
| 5 | Network security | Explain how to restrict server access |
| 6 | Identity and permissions | Understand who can access and manage resources |
| 7 | Monitoring and cost control | Identify basic resource problems and manage costs |
| 8 | Mini-project and revision | Complete an Azure Infrastructure Fundamentals project |

## Repository structure

```text
azure-infrastructure-fundamentals-phase-2/
├── README.md

├── project/              # Student Placement Portal mini-project
└── inventory/            # Resource inventory template
```

## Mini-project

The project designs a proposed Azure infrastructure for a **Student Placement Portal**. It considers Azure App Service, Azure SQL Database, Blob Storage, networking, Microsoft Entra ID, Azure RBAC, managed identities, Azure Monitor and Cost Management.

> **Learning-project note:** This repository documents a proposed design, not a deployed production environment. Example names and configurations are illustrative. No live Azure resources are created by this repository.

## How to use

1. Read the weekly notes in `docs/`.
2. Review the architecture and security decisions in `project/`.
3. Use `inventory/resource-inventory.csv` to record resources if you deploy them.
4. Replace example values with verified details from your own Azure environment.
5. Add screenshots or deployment evidence only if you actually performed those steps. Remove sensitive information before committing.
